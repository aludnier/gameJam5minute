# GameJam - 5 Minute
This project is the fruit of a 2-days GameJam at Epitech

## Theme
The theme of the GameJam was 5 Minute with the following constraint :
  - The time must be a ressource
  - add visual effect (shooting / hit / etc..)
  - add a tomato

## Engine
The project is made with **Godot**, and includes executables for both **Linux** and **Windows**.

## Project
This Game is a survival game where the goal is simple : 
  Kill as many enemies as possible in **5 minutes**

but enemies will try to attack and if you get hit you will lose **15 secondes** on your timer
To help you there is tomato on the ground that you can collect.

Collect 3 tomato to unlock a power-up from this pool :
### Power-ups
- **Pepper** : Move faster and jump higher  
- **Carrot** : Freeze the timer for 20 seconds (enemies can still hit you)  
- **Tomato** : After a short delay, a giant tomato falls from the sky and kills all enemies on the map
